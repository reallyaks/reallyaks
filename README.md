I build small legal and agent tools.

- [clause-diff](https://github.com/reallyaks/clause-diff) — DOCX redline with moves, cross-references, and phrase comments
- [citation-check](https://github.com/reallyaks/citation-check) — US case-citation form checker, offline by default
- [agent-trace-eval](https://github.com/reallyaks/agent-trace-eval) — agent scorecard; the citation-refusal task is the one that matters
- [hearing-timeline](https://github.com/reallyaks/hearing-timeline) — hearing transcript to a timeline

Stack: Python, OpenAI-compatible APIs, sqlite or plain files. Clause Diff is Node.
